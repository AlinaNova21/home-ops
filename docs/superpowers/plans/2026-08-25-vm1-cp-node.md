# Add `whoverse-vm1` Control-Plane Node Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Provision a new Talos **control-plane** node `whoverse-vm1` (PVE VM 226 on `root@pve1`, IP `192.168.2.26`) that is configuration-identical to the existing w2 PVE VM, joins the whoverse cluster as the 4th control plane, and is documented in the repo README.

**Architecture:** (1) Cloud: hand-create PVE VM 226 mirroring 225. (2) Repo: add `whoverse-vm1` to `talconfig.yaml` as `controlPlane: true` with w2's networking patches, a per-node schematic (CP extension set + `qemu-guest-agent`), and a w2-style 32GiB `miroir` volume. (3) Generate Talos configs with `talhelper genconfig` and validate with `flate`. (4) Operational: boot VM, install Talos in maintenance mode, join the existing cluster, verify quorum/health. The existing `controlPlane:` block (OIDC, kubelet/kernel-miroir, EPHEMERAL volume, watchdog, proxy-disabled) applies automatically to the new node — no changes there.

**Tech Stack:** PVE (`qm`), Talos `v1.13.9`, talhelper (`talhelper genconfig`), Kubernetes `v1.36.2`, flate, pre-commit.

**Spec reference:** `docs/superpowers/specs/2026-08-25-vm1-cp-node-design.md`

## Task 1: Create PVE VM 226 (CLUSTER-AFFECTING — consent gate)

**Files:** none in repo. Runs on `root@pve1`.

**Verify 226 is free first:**

- [ ] **Step 1: Confirm VM ID 226 is unused**

```bash
ssh root@pve1 'test -f /etc/pve/qemu-server/226.conf && echo "IN USE (abort)" || echo "226 FREE"'
```
Expected: `226 FREE`

- [ ] **Step 2: Create VM 226 as a mirror of 225**

Reference the source (`.conf` of 225) and create 226 with the new name, MAC, and disk. Reason: `qm clone` would carry w2's installed disk + serials; a fresh `qm create` gives a clean disk to install Talos on.

```bash
ssh root@pve1 'qm create 226 \
  --name whoverse-vm1 \
  --ostype l26 \
  --sockets 1 \
  --cores 4 \
  --cpu x86-64-v2-AES \
  --memory 8192 \
  --balloon 0 \
  --agent enabled=1,fstrim_cloned_disks=1 \
  --scsihw virtio-scsi-single \
  --net0 virtio=BC:24:11:7C:E7:E9,bridge=vmbr0,tag=1 \
  --scsi0 zfs-iscsi:128 \
  --ide2 scale-smb:iso/nocloud-amd64.iso,media=cdrom \
  --boot order=scsi0\;ide2 \
  --nameserver 192.168.2.1 \
  --searchdomain local \
  --onboot 1 \
  --numa 0'
```

- [ ] **Step 3: Verify the resulting config**

```bash
ssh root@pve1 'cat /etc/pve/qemu-server/226.conf'
```
Expected fields (must match):
```
name: whoverse-vm1
net0: virtio=BC:24:11:7C:E7:E9,bridge=vmbr0,tag=1
scsi0: zfs-iscsi:<disk-0>,size=128G ...
cores: 4
memory: 8192
agent: 1,...
ide2: scale-smb:iso/nocloud-amd64.iso,...  # Talos nocloud installer ISO
```
If `scsi0` shows a different disk id than `vm-226-disk-0`, note it (Talos only needs `/dev/sda`; the id doesn't matter to the node config).

- [ ] **Step 4: Confirm MAC/name uniqueness on the LAN** (no DHCP/ARP collision for `BC:24:11:7C:E7:E9`).

> **STOP — explicit consent required before detaching the IDE and booting, and for Task 6 (join).**

## Task 4: Add the `whoverse-vm1` node to `talconfig.yaml`

**Files modified: `talos/whoverse/talconfig.yaml`**

- [ ] **Step 1: Insert the node block after the `whoverse-w2` entry** (before `controlPlane:`)

Add:
```yaml
  - hostname: whoverse-vm1  # VM (libvirt) - control plane
    ipAddress: 192.168.2.26
    controlPlane: true
    installDisk: /dev/sda
    patches:
      - "@./miroir-disk-vm-tiny.yaml"
      - "@./patches/networking/common.yaml"
      - "@./patches/networking/vm.yaml"
    schematic:
      customization:
        systemExtensions:
          officialExtensions:
            - siderolabs/iscsi-tools
            - siderolabs/realtek-firmware
            - siderolabs/gvisor
            - siderolabs/qemu-guest-agent
            - siderolabs/amdgpu
            - siderolabs/i915
            - siderolabs/xe
            - siderolabs/drbd
```

Note: talhelper's per-node `schematic` **replaces** (does not merge) the role-level `controlPlane.schematic`, so **all** extensions must be listed here (the CP set + `qemu-guest-agent`). `controlPlane.patches` (OIDC, kubelet/kernel-miroir, EPHEMERAL volume, watchdog, proxy) still apply to this node automatically because it is a control plane.

- [ ] **Step 2: Verify the node parses**

```bash
yq '.nodes[] | select(.hostname=="whoverse-vm1") | {hostname, ipAddress, controlPlane, installDisk}' talos/whoverse/talconfig.yaml
```
Expected: hostname `whoverse-vm1` / ip `192.168.2.26` / controlPlane `true` / installDisk `/dev/sda`.

- [ ] **Step 3: Validate yukup yaml / no duplicate IP**

```bash
yq '[.nodes[].ipAddress]' talos/whoverse/talconfig.yaml | sort | uniq -d | grep -q "." && echo "DUPLICATE IP (abort)" || echo "IPs unique"
```
Expected: `IPs unique`

## Task 8: Join `whoverse-vm1` to the live cluster (CLUSTER-AFFECTING, consent gate)

Run only **after** VM creation (Task 1) is complete and the user says continue. This installs Talos on the new control plane and joins it as an etcd/quorum member.

- [ ] **Step 1: Boot VM 226** (detached from IDE, power on)

```bash
ssh root@pve1 'qm set 226 --ide2 none,media=cdrom; qm start 226'
```
Wait for the ISO to come up in maintenance mode and Talos to get DHCP at `192.168.2.26`.

- [ ] **Step 2: Obtain the generated node config**

```bash
cd /home/alina/projects/home-ops/.worktrees/feat/vm1-cp-node
CFG=talos/whoverse/clusterconfig/whoverse-whoverse-vm1.yaml
talosctl verify -n 192.168.2.26 -i prepare $CFG   # confirm reachable in maintenance
```

- [ ] **Step 3: Apply the config with `--insecure` (install to the new node only)**

**Important:** `just talos-apply-insecure` applies to *all* nodes in `talconfig.yaml`. Here, apply **only** to the new node to avoid touching existing nodes:

```bash
timeout 300 talosctl apply-config --insecure -n 192.168.2.26 \
  -f talos/whoverse/clusterconfig/whoverse-whoverse-vm1.yaml
```
Talos installs to `/dev/sda` and reboots. Wait for it to come back.

- [ ] **Step 4: Verify the node joins the cluster and control plane**

```bash
talosctl -n 192.168.2.26 health
talosctl -n 192.168.2.26 etcd members
```
Expected: node listed; etcd returns expected members (4-member control plane).

- [ ] **Step 5: Verify Kubernetes node Ready + control-plane**

```bash
kubectl get node -o wide
```
Expected: `whoverse-vm1` `Ready`, `control-plane` role, IP `192.168.2.26`.
